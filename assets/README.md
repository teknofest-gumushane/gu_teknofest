# Asset notları

## `images/logo.png`

Resmi TEKNOFEST logosu (Havacılık, Uzay ve Teknoloji Festivali). Kullanıcının sağladığı 1920 px dosyadan
512 px'e küçültülmüştür; çizim değiştirilmemiş, yeniden çizilmemiştir. Tarayıcı ikonları
(`web/favicon.png`, `web/icons/*`) aynı dosyadan üretilmiştir.

TEKNOFEST adı ve logosu T3 Vakfı'nın tescilli markasıdır. Logonun bu sitede kullanım izni ve kurumsal
kimlik kuralları (boşluk, zemin, en küçük boyut) kulübün sorumluluğundadır; logoyu değiştirme, kırpma,
yeniden renklendirme.

Karar: `docs/decisions.md` D-24.
